# 功能地图

共同前提：先按 [验证入口](../README.md) 启动并做对应的只读自检，命令工作目录是候选检出根目录，`WORKFLOW_EVIDENCE_ROOT` 是本次唯一的绝对路径。发生失败也按入口收拾现场，取证保留命令、输出、退出码和结束状态；地图里的每个入口都要覆盖。

| 功能页 | 子功能编号 | 用户感知的结果 |
|---|---|---|
| [汇报页面](report.md) | report.1—report.7 | 汇报没有脚本错误和布局溢出，三组截图可读 |
| [从候选目录安装](install.md) | install.1—install.4 | 候选文件装到两个框架后内容相同、接入自检通过、临时仓库已删除 |
| [各框架最小派发](dispatch.md) | dispatch.1—dispatch.3 | 只读任务按三框架解析，真实运行时能核对隔离、用量和记录 |

同一功能的子功能共用一条用户路径，按编号逐条核对结束状态。工单【实测】可引用单个编号或一段编号，但证据必须覆盖引用的全部编号。派发默认只做预览；真实运行的证明范围由工单明确给出。
