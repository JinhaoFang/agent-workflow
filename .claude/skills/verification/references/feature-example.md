# 搜索笔记

用户按标题或正文找到笔记，打开结果，并能分清"没有匹配"和"搜索不可用"。

## 子功能

- `search-open`：从每个入口打开搜索框。
- `search-match`：标题和正文都能匹配，不改动笔记数据。
- `search-empty`：没有匹配时显示完整的空状态。
- `search-cli`：命令行返回和页面相同的匹配。

## 用户从哪里进入

- 页面工具栏的「搜索」按钮。
- 页面焦点不在输入框时按 `/`。
- 终端运行 `notes search <关键词>`。

## 怎么驱动

前提：

- 笔记服务在 `http://127.0.0.1:4173` 正常，自检报告的地址和数据目录符合预期。
- 临时数据目录里有标题为「季度计划」、正文含「预算草稿」的笔记。

- **工具栏进入**：运行 `./drive.mjs click --role button --name "搜索"`。出现名为「搜索笔记」的对话框，焦点在搜索框里。
- **键盘进入**：关掉对话框，焦点放回页面，运行 `./drive.mjs press --key "/"`。出现同一个对话框，页面里没有多出斜杠。
- **标题匹配**：运行 `./drive.mjs fill --role searchbox --name "搜索笔记" --value "季度"`。结果列表有「季度计划」。
- **空状态**：运行 `./drive.mjs fill --role searchbox --name "搜索笔记" --value "火山"`。搜索结束后出现「没有匹配的笔记」。
- **命令行匹配**：运行 `notes search "季度" --format json`。退出码 0，输出里有一个标题为「季度计划」的对象。
- **取证**：运行 `./drive.mjs screenshot --path <证据目录>/search/results.png`，截图里能看到产品名称、关键词和「季度计划」。

## 坑

- 焦点在编辑器或搜索框里时，按 `/` 会输入文字，打不开搜索。
- 结果有短暂防抖，等结果列表或空状态出现，不用固定时长的等待。
- 命令行默认输出给人看的格式，断言时加 `--format json`。
